VISCOM Instalação
Python + OpenCV

Processamento de imagens para explorar a visão computacional.

O VisCom é um aplicativo desktop para processamento digital de imagens, filtros artísticos, análise visual e reconhecimento facial com chamada automática. Ele roda localmente em Tkinter e OpenCV — esta página é apenas a apresentação do projeto.

Ver no GitHub Conhecer funcionalidades

O que o VisCom faz

Uma ferramenta modular para estudar e aplicar operações clássicas de PDI e visão computacional em uma interface gráfica ou no terminal.

Operações básicas

Brilho, contraste, soma, subtração, escala de cinza, HSV, redimensionamento, recorte, rotação e espelhamento.

Filtros e análise

Filtros de média, mediana e gaussiano, nitidez, Sobel, Canny, histogramas, equalização, canais, binarização e quantização.

Segmentação

Crescimento de regiões, morfologia, contornos, retas e círculos de Hough e detecção de cantos Shi-Tomasi.

20 estilos artísticos

Filtros prontos inspirados em estilos fotográficos, com intensidade ajustável e prévia na GUI.

Reconhecimento facial

Detecção Haar Cascade e reconhecimento LBPH para cadastro, treinamento e identificação local.

Várias entradas

Chamada por foto, pasta, vídeo ou câmera ao vivo, além de uma GUI desktop e uma CLI para uso headless.

Módulos do projeto

MóduloResponsabilidade
processamento.pyFunções puras de processamento e visão computacional.
filtros.pyComposição dos 20 estilos artísticos.
reconhecimento.pyHaar, LBPH, cadastro e sessões de chamada.
gui.pyInterface Tkinter com prévias, parâmetros, histórico e zoom.
main.pyMenu de terminal para operações e fluxos de reconhecimento.
test_*.pyTestes automatizados das operações, filtros, GUI e CLI.

Instalação e uso

Clone e entre no projeto

git clone https://github.com/LeonCS5/projeto_VisCom.git
cd projeto_VisCom

Crie um ambiente virtual

python -m venv .venv
source .venv/bin/activate

No Windows, use .venv\Scripts\Activate.ps1.

Instale as dependências

pip install -r requirements.txt

Escolha uma interface

python gui.py
# ou
python main.py

O cadastro e o reconhecimento facial geram dados localmente durante a execução. Não há fotos, modelos treinados, rótulos ou chamadas pessoais publicados neste site.
